
# 👑 Souverain Code (`souveraincode.com`)

> *"Le numérique souverain commence par un code que vous maîtrisez."*

Bienvenue sur le dépôt officiel de la landing page institutionnelle de **Souverain Code**, studio spécialisé dans le développement web sur-mesure, les applications mobiles et l'audit de sécurité des smart contracts.

---

## 🚀 Vision & Philosophie

**Souverain Code** incarne une ingénierie logicielle d'élite basée sur deux piliers :
- **La Souveraineté Technique :** Offrir à nos clients le contrôle absolu, l'autonomie et la sécurité sur leurs infrastructures.
- **L'Éthique & l'Excellence :** Un engagement de rigueur, de loyauté et de précision mathématique dans chaque ligne de code (1 Pierre 5:4).

---

## 🛠️ Stack Technique

Cette vitrine a été conçue pour être ultra-rapide, performante et autonome :

- **HTML5 Sémantique & Tailwind CSS :** Interface réactive, épurée et optimisée SEO.
- **JavaScript Vanilla :** Logique client fluide sans surcouche inutile (*Zero Overhead*).
- **Three.js :** Effets visuels et animations dynamiques 3D.
- **Calculateur d'Architecture & Terminal Interactif :** Estimation en direct des projets.
- **Web3Forms :** Traitement sécurisé des demandes de contact.
